Apson YTDownloader — wersja portable

Uruchom ApsonYTDownloader.exe. Plik .portable powoduje, że ustawienia, cache,
historia, logi i pliki tymczasowe trafiają do podkatalogu data obok aplikacji.

Wersja portable nie rejestruje protokołu apson-ytdownloader://. Jednoklikowy
przycisk przeglądarki jest dostępny po instalacji przez installer EXE.

Paczka nie jest podpisana cyfrowo. Windows SmartScreen może przy pierwszym
uruchomieniu wyświetlić ostrzeżenie.
